🧹 Text Preprocessing with Python
📌 Overview
This project demonstrates standard and advanced text preprocessing techniques commonly used in Natural Language Processing (NLP) workflows. It is a foundational step in preparing textual data for machine learning models or large language models (LLMs).
The Dataset i have used is : https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews
✅ Features
Lowercasing

Removing punctuation, stopwords, and numbers

Tokenization

Lemmatization / Stemming

Handling special characters and whitespace

Optional: Spell correction / contraction expansion

🧰 Technologies Used
Python 3.x

Jupyter Notebook

nltk, re, spacy, string, pandas
